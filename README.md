### Hi, I'm Tanya 👋

Graphics & 3D Vision Engineer in Daejeon, South Korea. I work on recovering and representing human body in 3D: parametric human models, 2D-to-3D reconstruction, spatial perception, and real-time rendering. Before that, I was a technical artist shipping real-time shaders and optimizing graphics for XR applications.

**Currently working on**

- [**AvatarStudio**](https://github.com/chibisova/AvatarStudio): a Qt/OpenGL application for interactive parametric human modeling, MHR visualization, and measurement-driven body shape fitting
- [**GNM Avatar**](https://github.com/chibisova/gnm-avatar): Exploring single-image 3D head reconstruction using Google's Generative Anthropometric Model, MediaPipe landmarks, and PyTorch optimization
