### Hi, I'm Tanya 👋

Graphics & 3D Vision Engineer in Daejeon, South Korea. I work on recovering and representing the human body in 3D: parametric human models, 2D-to-3D reconstruction, and body tracking. Before that, I was a technical artist shipping real-time shaders and avatar systems for VR.

**Currently working on**

- [**AvatarStudio**](https://github.com/chibisova/AvatarStudio): a Qt/OpenGL viewer for the MHR body model, plus real-time measurement-driven shape fitting via Jacobians

**Tools:** C++ · Python · C# · HLSL/GLSL · OpenGL · OpenCV · PyTorch · Unity · Blender
